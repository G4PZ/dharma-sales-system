# Dharma Sales System

Sistema web inteligente para la gestión del proceso de ventas de Dharma E.I.R.L.

## Tecnologías

- Frontend: Next.js
- Backend: Python / FastAPI
- Base de datos: PostgreSQL
- Administración de base de datos: pgAdmin

## Módulos principales

- Productos
- Clientes
- Ventas
- Comprobantes electrónicos
- Notas de crédito
- Integración con SUNAT
- Alertas de operaciones inusuales mediante IA
